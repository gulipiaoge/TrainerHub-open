# TrainerHub

一个**纯本地**运行的游戏修改器 / Mod 管理工具。用 Python + pywebview(WebView2) 写成的 Windows 桌面应用，把「游戏 → 修改器 / Mod」的对应关系理清楚，让 Mod 能装进游戏目录、也能安全卸干净。

> 界面为中文。数据全部保存在你自己电脑的 `data/` 目录里，不上传任何服务器。

---

## ✨ 功能

| 模块 | 说明 |
|---|---|
| **游戏库** | 以**游戏为主体**组织一切，点进游戏才看到它的修改器和 Mod；同一个游戏不会重复出现 |
| **修改器库** | 本地导入或在线下载的修改器，统一挂在对应游戏下，显示来源与添加时间 |
| **修改器在线下载** | 从公开站点检索免费独立版修改器；**下载前必须选择归入哪个游戏**，不会凭空生成游戏 |
| **Mod 管理** | 导入本地 Mod → 安装进游戏目录 → 随时卸载/移除，安装目录有明确指引 |
| **快捷键说明** | 常用修改器热键速查 |
| **设置** | 首次使用须知、数据目录位置等 |

### 设计上比较在意的地方

- **数据以游戏为中心**：修改器和 Mod 都归属于某个游戏，避免"同一个游戏出现两条"。
- **添加时间可追溯**：文件型条目用文件创建时间，链接型条目用记录时间兜底。
- **卸载干净且不伤游戏**：只移除本工具**记录过**的文件，删除前校验路径必须位于 Mod 目录内（防目录穿越），游戏运行中拒绝删除。
- **单实例运行**：重复启动不会开出第二个窗口，避免旧进程占用导致"改了没生效"。
- **不碰系统**：不写注册表、不装系统服务、不改系统环境变量。

## 🚀 快速开始

### 方式一：一键启动（Windows）

1. 克隆或下载本仓库
2. 首次运行前创建虚拟环境并安装依赖：
   ```bat
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
3. 双击 `launch.bat`（或 `启动器.bat`）

### 方式二：手动运行

```bat
.venv\Scripts\python app.py
```

### 依赖

- **Python 3.10+**（开发环境为 3.13）
- **Microsoft Edge WebView2 Runtime**（Windows 10/11 通常已预装；若窗口打不开请安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)）

## 📁 目录结构

```
TrainerHub/
├── app.py           # 窗口、pywebview 桥接、单实例保护、任务栏图标
├── backend.py       # 数据模型、Mod 安装/卸载、在线检索与下载
├── sync_github.py   # 通过 GitHub API 同步代码到远端仓库
├── web/             # 前端（原生 HTML / CSS / JS，无需构建）
│   ├── index.html
│   ├── app.js
│   └── style.css
├── data/            # 运行时数据（已 gitignore，不入库）
│   ├── games.json       # 游戏主体
│   ├── library.json     # 修改器库
│   ├── mods_*.json      # 各游戏的 Mod 列表
│   └── mods/            # 导入的 Mod 文件
├── requirements.txt
├── THIRD_PARTY_NOTICES.md
├── LICENSE
└── icon.ico
```

> `data/` 目录**已在 `.gitignore` 中排除**。它含有你本机的游戏安装路径，属于个人隐私，不应进入版本库。首次运行会自动创建。
